# Воздушный шар

Бонусная веб-игра для кейса «Столото» на Чемпионате России 2026 по продуктовому программированию. Игрок выбирает маршрут и ставку, поднимается на воздушном шаре и решает, когда забрать выигрыш. Очки формируют рейтинг пилотов, а каждый завершённый полёт пополняет коллекцию марок.

Игра использует бонусные баллы. Покупок и денежных призов нет.

## Как играть

1. Выбери зелёный маршрут с 9 уровнями или красный с 12.
2. Выбери один из четырёх фрагментов ставки. Каждый задаёт стоимость полёта и силу бустера.
3. Нажми «Начать полёт». Страница плавно перейдёт к игровому полю, и шар начнёт подъём.
4. После первого уровня нажми «Забрать», пока шар не лопнул. Выигрыш равен ставке, умноженной на текущий коэффициент.
5. Получи очки и марку. Собери шесть разных марок, чтобы обменять полный альбом на 200 бонусов при исходных настройках.

После получения выигрыша полёт продолжается. Если шар лопнул раньше, чем игрок забрал бонусы, ставка теряется, но заработанные очки и марка сохраняются.

## Возможности игры

- Два вида оформления: классический и небесный с панорамным полем, облаками и деревушкой.
- Плавный взлёт шара и движение неба. В небесном оформлении игра занимает экран, а кнопка «Забрать» остаётся под рукой.
- Четыре ставки и бустеры, которые усиливают коэффициент на одном из уровней.
- Рейтинг пилотов, общая история полётов и коллекция из шести марок.
- Правила до начала игры, подсказки, звуки по выбору игрока и проверка данных завершённого раунда.
- Сохранение прогресса при обновлении страницы и повторная игра с выбранным маршрутом.
- Оформление для компьютеров и телефонов, поддержка настройки уменьшенного движения.
- Панель управления ставками, наградами и параметрами полёта.

## Запуск

Требуется **JDK 21 или новее**. Из папки проекта:

```bash
bash run.sh
```

| Страница | Адрес |
| --- | --- |
| Игра | http://127.0.0.1:443 |
| Управление | http://127.0.0.1:443/admin |
| Презентация | http://127.0.0.1:443/presentation |

Для Windows предусмотрен `run.bat`. Чтобы выбрать другой порт, например при запуске в Ubuntu без прав на порт 443:

```bash
PORT=8090 bash run.sh
```

В этом случае адрес игры — **http://127.0.0.1:8090**. На страницах управления и презентации используется тот же порт.

## Подготовка к защите

Для показа заданных игровых ситуаций запусти демонстрационный режим:

```bash
bash run-demo.sh
```

При необходимости другого порта: `PORT=8090 bash run-demo.sh`.

1. Открой игру. Новый пилот получает 1 000 бонусов; имя можно изменить в шапке страницы.
2. Во второй вкладке того же браузера открой `/admin`. Пароль для демонстрационного доступа: `admin-demo-2026`.
3. Выбирай сценарий перед каждым показом. Он действует на один следующий раунд этого пилота. Демонстрационные полёты отмечены в интерфейсе.
4. Открой `/presentation`: восемь слайдов с планом выступления на 6 минут 55 секунд. Переключение — стрелками или кнопками, доступен полноэкранный режим.
5. Для показа рейтинга открой игру в другом браузере или приватном окне и создай второго пилота.

## Что показать комиссии

| Этап | Действия | Что видно в игре |
| --- | --- | --- |
| Выбор и запуск | Открыть правила, выбрать маршрут и ставку, начать полёт | Плавный переход к полю, взлёт шара и списание ставки |
| Получение выигрыша | Выбрать «Успешный полёт» в управлении, взять ставку без бустера, нажать «Забрать» после первого уровня | Бонусы зачислены, шар продолжает полёт, затем появляются результат, очки и марка |
| Проигрыш | Выбрать «Ранний крах», начать полёт и дождаться завершения | Ставка потеряна, игрок получает марку |
| Усиление | Выбрать «Бустер на 2-м уровне», взять фрагмент ×3 и дождаться второго уровня | Коэффициент увеличивается втрое, начисляются очки за бустер |
| Управление | Изменить «Очков за уровень» на 37 и начать новый полёт | За каждый пройденный уровень начисляется 37 очков; после показа вернуть 10 |
| Прогресс | Открыть рейтинг, историю и коллекцию | Результаты пилотов, заработанные очки и собранные марки |

После завершения раунда страница остаётся у игрового поля. «Играть снова» возвращает к ставкам; без действий окно результата закрывается через 10 секунд.
