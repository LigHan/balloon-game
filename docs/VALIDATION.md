# Проверки

Проверено в macOS arm64, OpenJDK/JBR 21.0.3, Node.js 22.13.1, Python 3.12.6 и отдельном headless Chrome 152.0.7977.84.

## Выполнено

- Java компилируется с `--release 21 --add-modules jdk.httpserver`.
- `bash test.sh`: 100 утверждений в 9 группах тестов сервиса. Проверены идемпотентные ставки, 30 одновременных cashout, 20 одновременных запусков с одним ключом, ранний/поздний cashout, усиление, запрет усиления после cashout, сохранение очков, награды, альбомы, недостаточный баланс, разные темы, конфигурация, восстановление и SHA-256.
- `bash test-http.sh`: обязательные сценарии на настоящем отдельном Java-сервере с временными данными. Проверены HTTP-роуты, сессии, CSRF/Origin, административный пароль, валидация запросов и параметров, 12 одновременных cashout, общая история двух пилотов, бустер и перезапуск процесса. Число HTTP-утверждений зависит от числа запросов ожидания тиков.
- `python3 tests/model_analysis.py`: 100 000 исходов для каждого из четырёх наборов параметров, отклонение от теоретической вероятности меньше 1 процентного пункта. Результаты сохранены в CSV.
- Синтаксис игровых, общих и административных скриптов, включая `web/sky-scene.js`, проверяется `node --check`.
- `node --test tests/request_id_test.cjs`: генерация ключа запроса при отсутствии `crypto.randomUUID`, формат UUID v4, 1 000 разных ключей, штатный API, сообщение для неподдерживаемого браузера и порядок подключения скриптов. Отсутствие `randomUUID` моделируется в Node.js VM; это не проверка в браузере.
- На изолированном Java-сервере с `PORT=18443` проверены выдача обновлённых скриптов и начало раунда с ключом, созданным без `randomUUID`. Повторный запрос возвращает тот же раунд и списывает ставку только один раз.
- Локальный HTTP-сервер отвечает на `/health`. Основная графика находится внутри проекта, прозрачность PNG подтверждена.

## Браузерная проверка интерфейса

`tests/browser_ui_test.cjs`: успешно пройдены 122 проверки. Тест запускает отдельный Java-сервер на свободном локальном порту с временными данными, затем проверяет сайт в чистом браузерном контексте:

- Оба дизайна на ширинах 320, 375, 768, 1024, 1440 и 1920 px; отсутствие горизонтального переполнения и обрезки заголовка.
- Масштаб деревушки и заполнение нижнего края на экранах 375×812, 1440×900, 1920×1080, 2560×1440, 3440×1440 и 1080×2400. Проверены пропорции SVG, покрытие фоном всей высоты окна и соответствие пикселей в нижних углах и по центру исходной иллюстрации.
- Единственную панель ставки, её перенос внутрь/наружу игрового поля, сохранение выбранного дизайна после перезагрузки.
- Открытие и анимированное закрытие окон кнопкой, Escape и кликом по фону; фокус внутри окна, блокировку прокрутки страницы и отмену закрытия при быстром повторном открытии.
- Прокрутку длинных правил на мобильной ширине с неподвижными шапкой и кнопкой внизу.
- Сохранение имени, успешный полёт в обоих дизайнах, окно результата и повторную игру; корректное закрытие вложенной проверки честности.
- Неизменную координату классического поля до и после старта, подсказку над cashout и сохранение раунда/баланса при переключении дизайна в полёте.
- Покрытие всей страницы небесным фоном, движение облаков вниз одновременно с подъёмом шара, блокировку колеса, сенсорного свайпа в эмуляции Chrome и PageDown в активном полёте.
- Доступность cashout и положение шара на экранах 375×700, 320×568, 844×390 и 1024×700; восстановление активного полёта и блокировки после перезагрузки.
- Сохранение блокировки при закрытии окна поверх полёта, разблокировку после выигрыша и проигрыша, возврат к прежнему положению страницы и возможность снова прокручивать её.
- Сохранение цвета корзины в красном режиме по снимкам на одинаковой подложке; отключение анимации окон и небесного фона при `prefers-reduced-motion: reduce`; отсутствие ошибок JavaScript.

Снимки сохраняются в `test-results/ui/` и исключены из Git. Десктопные и мобильные снимки игры и модальных окон просмотрены. Браузер работает с отдельным временным профилем.

Для повторения нужны Node.js 20+, установленный Google Chrome и JDK 21+. Из корня проекта:

```bash
bash test.sh
npm install --prefix /tmp/balloon-ui-qa playwright --no-audit --no-fund
NODE_PATH=/tmp/balloon-ui-qa/node_modules BALLOON_BROWSER_CHANNEL=chrome node tests/browser_ui_test.cjs
```

Если Chromium установлен средствами Playwright, переменную `BALLOON_BROWSER_CHANNEL` можно не задавать.

## Не подтверждено

Привязка к порту 443 по умолчанию на этой macOS завершилась системным `Permission denied`; права процесса не менялись. HTTP-сценарии проверены на непривилегированных тестовых портах. На целевой Ubuntu доступ к 443 зависит от прав службы и настроек ОС.

Перед сдачей остаётся проверить Safari и Firefox, реальные сенсорные устройства, масштаб текста 200%, свайп закрытия рейтинга и плавность анимации на телефоне. 60 FPS не измерены. Браузерная проверка не покрывает отключение сети, автоматический возврат через 10 секунд и полноэкранную презентацию.

Dockerfile подготовлен, но Docker в окружении отсутствует. Для исходников выбран приватный репозиторий GitHub `LigHan/balloon-game`; перенос в GitVerse ожидает адреса репозитория для сдачи. PowerPoint-файл не создавался: презентация доступна в браузере.
